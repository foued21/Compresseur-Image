Detailed Description

Génération de grilles de segmentation à partir de QuadTrees.

Ce fichier contient la déclaration de la fonction permettant de générer une grille de segmentation à partir d'un QuadTree. La grille est sauvegardée en tant qu'image au format PGM.

Génère une grille de segmentation à partir d'un QuadTree.

Cette fonction parcourt un QuadTree pour dessiner les bordures des blocs uniformes, créant ainsi une grille de segmentation. Le résultat est ensuite sauvegardé dans un fichier PGM.

Parameters
pixmapLa Pixmap de référence (dimensions de l'image).
