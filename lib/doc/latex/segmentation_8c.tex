\doxysubsection{Detailed Description}
Génération de grilles de segmentation pour les images. 

Définit les fonctions pour dessiner et sauvegarder les grilles de segmentation basées sur un \doxylink{structQuadTree}{Quad\+Tree}.

Dessine les bordures des blocs définis par le \doxylink{structQuadTree}{Quad\+Tree} dans une \doxylink{structPixmap}{Pixmap}.
